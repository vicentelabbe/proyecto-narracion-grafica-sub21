
# Recursos visuales — El mito del abismo

## Identidad visual

La webstory utiliza la identidad visual definida
por el equipo durante la Entrega 04.

### Colores

- Negro carbón: #111111
- Blanco hueso: #F5F5F0
- Verde eléctrico: #C6FF36

### Tipografías

- Anton: títulos y encabezados.
- Inter: textos, explicaciones y navegación.

### Recursos implementados

- Portada con título y bajada.
- Menú de navegación entre capítulos.
- Botón interactivo de acceso a la visualización.
- Secciones con fondos claros y oscuros.
- Dos visualizaciones interactivas.
- Diseño adaptable a distintos dispositivos.

### Recursos gráficos adicionales

El equipo debe revisar si corresponde incorporar
el logotipo, fotografías y otros elementos
del manual de identidad de la Entrega 04.

No se incorporarán imágenes sin verificar su
procedencia y autorización de uso.

### Estado

Sistema visual preliminar implementado mediante
HTML, CSS y JavaScript.

Pendiente: comprobar su funcionamiento, contrastar
el resultado con el manual de identidad y completar
