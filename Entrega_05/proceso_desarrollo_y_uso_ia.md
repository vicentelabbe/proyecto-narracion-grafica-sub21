
# Proceso de desarrollo y uso de IA
## Entrega 05 — El mito del abismo

### 1. Objetivo de la webstory

Desarrollar una historia periodística digital sobre la regla Sub-21 en el fútbol chileno, integrando los materiales producidos durante el semestre.

La webstory busca comunicar información sobre las oportunidades de participación juvenil, las diferencias entre clubes y las trayectorias posteriores de los futbolistas analizados.

### 2. Relación con las entregas anteriores

El proyecto retoma la hipótesis, los textos, las visualizaciones y las decisiones de diseño preparadas en las entregas 03 y 04.

La identidad visual definida previamente se implementa mediante CSS, utilizando negro carbón, blanco hueso, verde eléctrico y las tipografías Anton e Inter.

La estructura narrativa contempla introducción, explicación de la regla, visualizaciones, trayectorias y conclusiones.

### 3. Implementación técnica

Se utilizan tres archivos principales:

- index.html: estructura narrativa y contenido.
- style.css: colores, tipografías, diseño y adaptación a pantallas.
- script.js: interacciones y navegación.

También se incorpora vis_02.html, una visualización interactiva elaborada con Python y Altair en una entrega anterior.

### 4. Registro de uso de inteligencia artificial

Herramienta utilizada: ChatGPT.

Principales solicitudes realizadas, resumidas:

- Orientación para organizar las carpetas del repositorio.
- Generación de código JavaScript para un botón de navegación.
- Apoyo para estructurar la documentación técnica.

La herramienta se utilizó como apoyo para la implementación y organización del trabajo.

### 5. Cambios y soluciones

Durante el desarrollo se realizaron los siguientes ajustes:

- Creación de la carpeta docs.
- Creación de index.html, style.css y script.js.
- Corrección de la ubicación del enlace CSS dentro de head.
- Incorporación de la visualización 02.
- Incorporación de secciones preliminares para organizar la historia.

### 6. Validaciones pendientes

Antes de la entrega se debe:

- Verificar las cifras y fuentes de las bases de datos.
- Revisar los textos periodísticos y conclusiones.
- Integrar las visualizaciones restantes.
- Revisar el funcionamiento de todos los enlaces.
- Comprobar la visualización en computador y celular.
- Verificar las interacciones de JavaScript.
- Revisar el código sugerido por IA.
- Publicar y probar GitHub Pages.

### 7. Estado del desarrollo

La webstory se encuentra en una etapa preliminar.

La estructura técnica inicial está creada, pero todavía deben integrarse y validarse los contenidos periodísticos del equipo, completar las visualizaciones y realizar las pruebas de funcionamiento.

Este documento se actualizará a medida que avance la implementación.
