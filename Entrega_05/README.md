
# Entrega 05 — El mito del abismo

## Webstory: Las trayectorias del fútbol juvenil chileno

### 1. Resumen del reportaje

"El mito del abismo" es una webstory de periodismo de datos que investiga las oportunidades de participación y las trayectorias posteriores de futbolistas jóvenes en Chile.

El proyecto toma como punto de partida el Campeonato Nacional de 2019 y la regla Sub-21, que incentivaba la participación de jugadores juveniles.

A través del seguimiento de una cohorte de trabajo de 25 futbolistas y del análisis de minutos juveniles por club, buscamos comprender qué sucede después de las primeras oportunidades en el profesionalismo.

La historia contempla tres posibles recorridos: continuidad en Chile, salida al extranjero y participación en categorías inferiores.

### 2. Hipótesis

La hipótesis de trabajo plantea que las oportunidades de participación durante la etapa juvenil no garantizan, por sí solas, la consolidación profesional posterior.

La investigación busca examinar la relación entre los minutos disputados en 2019 y la continuidad competitiva de los futbolistas en los años siguientes.

**Estado de la hipótesis:** pendiente de contrastación definitiva.

Los datos todavía requieren verificación con fuentes documentales y registros individuales, por lo que no corresponde afirmar que la hipótesis ya fue demostrada.

### 3. Estructura narrativa

La webstory contempla los siguientes capítulos:

1. Una oportunidad de llegar a Primera.
2. La regla Sub-21.
3. Los minutos juveniles por club.
4. ¿Qué pasa después del debut?
5. Conclusiones y metodología.

La estructura se basa en el recorrido de usuario y el wireframe desarrollados en la Entrega 04.

### 4. Implementación técnica

La página está desarrollada mediante:

- HTML para la estructura narrativa.
- CSS para la identidad visual y el diseño responsive.
- JavaScript para las interacciones.
- Python y Altair para la generación de visualizaciones de datos.

La carpeta `docs` contiene los archivos de publicación.
